# SysProduto

Um CRUD para registro de produtos e manuseamento de estoque.

Para utiliza-lo basta você iniciar o programa no InteliJ e seguir com base no que esta indicando.

Na parte Produto, no campo Código é recomendado usar letras e caracteres(Ex.: A1BC2CD3).

No campo de Datas não pode ser  inserido uma data passada para a validade.

Na parte Categoria , no campo id não pode ser inserido valores 0 ou -1
No campo Setor é recomendado usar letras e caracteres(Ex.: A1, A2)

Após inserir todos os dados clique em Cadastrar e o produto será inserido na tabela ao lado.

Para buscar o produto basta inserir o código registrado na tabela e clicar em buscar.

Para excluir basta clicar no produto na tabela e depois em excluir.

Para registrar um novo produto basta clicar em limpar e inserir os novos dados.

Na tabela abaixo possui informações que estão na tabela com base nos produtos que foi inserido, como data de validade, quantidade de estoque, media de cada produto, agrupamento por base no setor e exibir todos os produtos.
